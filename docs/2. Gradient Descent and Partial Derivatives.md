# Gradient Descent and Partial Derivatives

> [!summary] Key idea
> **Gradient descent** changes a model's parameters in the direction that locally reduces loss. The **gradient** tells us which way the loss rises; the **learning rate** controls the size of each update. When a loss depends on multiple parameters, we calculate a **partial derivative** for each one.

## 1. From a derivative to an update

From [[1. Derivatives and Finite Differences]], we know:

$$
L(w)=(w-3)^2,\qquad \frac{dL}{dw}=2(w-3)
$$

A derivative gives the local slope. To reduce the loss, we usually move **opposite** that slope:

$$
\boxed{w_{\text{new}}=w_{\text{old}}-\eta\frac{dL}{dw}}
$$

- $w_{\text{old}}$: parameter before the update.
- $\eta$ (eta): **learning rate**, a positive number controlling the step size.
- $dL/dw$: slope calculated at the **current** value of $w$.
- $w_{\text{new}}$: parameter after the update.

**Important:** we subtract the *gradient scaled by the learning rate*, **not the loss value**.

### Why subtract?

- If the gradient is negative, subtracting it makes $w$ **increase**.
- If the gradient is positive, subtracting it makes $w$ **decrease**.

In our parabola, both effects move $w$ toward the minimum at $3$ for sufficiently small steps.

## 2. A gradient descent step by hand

Start at $w=0$ with learning rate $\eta=0.1$.

First calculate the loss and derivative:

$$
\begin{aligned}
L(0)&=(0-3)^2=\boxed{9}\\
\left.\frac{dL}{dw}\right|_{w=0}&=2(0-3)=\boxed{-6}
\end{aligned}
$$

Then update $w$:

$$
\begin{aligned}
w_{\text{new}}
&=0-0.1(-6)\\
&=\boxed{0.6}
\end{aligned}
$$

Check the new loss:

$$
L(0.6)=(0.6-3)^2=\boxed{5.76}
$$

The loss decreased from **9** to **5.76**. We moved toward $w=3$.

### Continue the iterations

At each iteration, use the **current** weight to calculate a **new** gradient:

| Iteration | $w$ before update | Gradient $2(w-3)$ | $w$ after update | New loss |
|---:|---:|---:|---:|---:|
| 1 | 0 | -6 | 0.6 | 5.76 |
| 2 | 0.6 | -4.8 | 1.08 | 3.6864 |
| 3 | 1.08 | -3.84 | 1.464 | 2.359296 |
| 4 | 1.464 | -3.072 | 1.7712 | 1.50994944 |

Notice that the gradient's magnitude decreases as $w$ approaches $3$. With this particular loss function and fixed learning rate, the updates become smaller.

> [!question] Pause and predict
> If you keep repeating these updates using $\eta=0.1$, what value do you expect $w$ to approach? Will the loss approach $0$?

## 3. What the learning rate changes

Take the same starting point, $w=0$, and the same gradient, $-6$.

With $\eta=0.1$:

$$
w_{\text{new}}=0-0.1(-6)=0.6
$$

With $\eta=0.2$:

$$
w_{\text{new}}=0-0.2(-6)=1.2
$$

The learning rate controls **how far we move along the negative gradient**, not the value of the gradient itself.

- **Too small:** progress may be very slow.
- **Appropriately sized:** updates can reduce the loss efficiently.
- **Too large:** updates can overshoot and oscillate, or even diverge.

For this *specific* quadratic, the update can be rewritten as:

$$
w_{\text{new}}-3=(1-2\eta)(w_{\text{old}}-3)
$$

This makes the behavior especially clear: if $0<\eta<1$, the distance to $3$ shrinks each step; at $\eta=1$ it oscillates without shrinking (unless already at the minimum); for $\eta>1$ it grows. **These thresholds are specific to this example, not universal neural-network rules.**

## 4. Why we need partial derivatives

Real models have many trainable parameters. Even a tiny linear model can have a weight $w$ and a bias $b$.

When the loss depends on both parameters, we write:

$$
L(w,b)
$$

The **partial derivative with respect to $w$** measures how loss changes when $w$ changes while $b$ is held fixed:

$$
\frac{\partial L}{\partial w}
$$

The **partial derivative with respect to $b$** measures how loss changes when $b$ changes while $w$ is held fixed:

$$
\frac{\partial L}{\partial b}
$$

Together, these form the **gradient vector**:

$$
\nabla L(w,b)=
\begin{bmatrix}
\frac{\partial L}{\partial w}\\
\frac{\partial L}{\partial b}
\end{bmatrix}
$$

The negative gradient points in the direction of steepest local decrease, under the ordinary Euclidean notion of distance.

## 5. Worked example: one weight and one bias

The example we solved was:

$$
\boxed{L(w,b)=(2w+b-5)^2}
$$

One way to interpret this:

- $2w+b$ is a model prediction for input $x=2$.
- $5$ is the target.
- The loss squares the prediction error.

### Derive both partial derivatives

Expanding the square gives:

$$
L(w,b)=4w^2+4wb-20w+b^2-10b+25
$$

Differentiate with respect to $w$, treating $b$ as constant:

$$
\begin{aligned}
\frac{\partial L}{\partial w}
&=8w+4b-20\\
&=\boxed{8w+4b-20}
\end{aligned}
$$

Differentiate with respect to $b$, treating $w$ as constant:

$$
\begin{aligned}
\frac{\partial L}{\partial b}
&=4w+2b-10\\
&=\boxed{4w+2b-10}
\end{aligned}
$$

These can also be written in factored form:

$$
\frac{\partial L}{\partial w}=4(2w+b-5),
\qquad
\frac{\partial L}{\partial b}=2(2w+b-5)
$$

The shortcut behind the factored form will make more sense after learning the chain rule in [[3. Chain Rule and Backpropagation]].

## 6. Our numerical exercise

Given:

$$
w=1,\qquad b=0,\qquad\eta=0.05
$$

### Step 1 — Calculate the initial loss

$$
\begin{aligned}
L(1,0)&=(2(1)+0-5)^2\\
&=(-3)^2\\
&=\boxed{9}
\end{aligned}
$$

### Step 2 — Calculate the gradient at the current parameters

$$
\begin{aligned}
\frac{\partial L}{\partial w}
&=8(1)+4(0)-20=\boxed{-12}\\
\frac{\partial L}{\partial b}
&=4(1)+2(0)-10=\boxed{-6}
\end{aligned}
$$

So:

$$
\nabla L(1,0)=
\begin{bmatrix}-12\\-6\end{bmatrix}
$$

**Interpretation from our discussion:** both components are negative, so the gradient descent update increases both $w$ and $b$. Since the magnitude of the weight gradient is twice the bias gradient, the weight update is twice as large when using the same learning rate.

### Step 3 — Update both parameters

$$
\begin{aligned}
w_{\text{new}}
&=w-\eta\frac{\partial L}{\partial w}\\
&=1-0.05(-12)\\
&=\boxed{1.6}\\[6pt]
b_{\text{new}}
&=b-\eta\frac{\partial L}{\partial b}\\
&=0-0.05(-6)\\
&=\boxed{0.3}
\end{aligned}
$$

### Step 4 — Check the new loss

$$
\begin{aligned}
L(1.6,0.3)
&=(2(1.6)+0.3-5)^2\\
&=(3.5-5)^2\\
&=(-1.5)^2\\
&=\boxed{2.25}
\end{aligned}
$$

Our actual result was:

| | Before update | After update |
|---|---:|---:|
| Weight $w$ | 1 | 1.6 |
| Bias $b$ | 0 | 0.3 |
| Loss $L$ | **9** | **2.25** |

> [!note] Multiple solutions can achieve zero loss
> In this toy example, any pair satisfying $2w+b=5$ has loss $0$. Gradient descent is finding *a* good parameter combination; this single training example does not uniquely determine the weight and bias.

## 7. Training vocabulary

| Term | Meaning |
|---|---|
| **Parameter** | A value the model learns, such as $w$ or $b$ |
| **Loss** | A quantity measuring the model's error |
| **Derivative / partial derivative** | Sensitivity of loss to one variable |
| **Gradient** | Collection of partial derivatives |
| **Learning rate** | Scales each optimization step |
| **Gradient descent** | Updates parameters using negative gradients |
| **Iteration** | One cycle of computing gradients and updating parameters |

**Remember:** a loss value is not itself an instruction for how to change parameters. The gradient supplies that direction information.
